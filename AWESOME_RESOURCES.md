## 🤖 **TinyML & Edge AI Frameworks**

<table>
<tr>
<td width="50%">

### ⭐ **Must-Have Frameworks**

#### **[TensorFlow Lite Micro](https://github.com/tensorflow/tflite-micro)** ![](https://img.shields.io/github/stars/tensorflow/tflite-micro?style=social)
> **The standard for ML on microcontrollers**
- ✨ 2024: **Memory-optimized kernels** for Cortex-M
- 🚀 Support for INT8, INT16 quantization
- 💪 150+ operators optimized for embedded
- 🎯 Works with STM32, ESP32, Arduino

#### **[Edge Impulse](https://github.com/edgeimpulse/edge-impulse-sdk)** ![](https://img.shields.io/github/stars/edgeimpulse/edge-impulse-sdk?style=social)
> **End-to-end embedded ML platform - Industry leader**
- 🎨 No-code ML model training
- 📱 Built-in data acquisition tools
- ⚡ Automatic optimization for embedded targets
- 🏆 **2024 winner: Best TinyML Platform**

#### **[CMSIS-NN](https://github.com/ARM-software/CMSIS-NN)** ![](https://img.shields.io/github/stars/ARM-software/CMSIS-NN?style=social)
> **ARM's official neural network library**
- 🚀 **2024 update**: SVE2 support for Cortex-M55+
- ⚡ 5x faster convolutions with DSP instructions
- 🎯 Optimized for Cortex-M4/M7/M55
- 💾 Ultra-low memory footprint

</td>
<td width="50%">

### 🔥 **Trending in 2024-2025**

#### **[microTVM](https://tvm.apache.org/docs/topic/microtvm/)** ![](https://img.shields.io/badge/TVM-Apache-orange)
> **Apache TVM for microcontrollers - Game changer**
- ✨ **NEW 2024**: AutoTVM for embedded devices
- 🎯 Compiles models to bare-metal C
- 🚀 Beats TFLite by 2-3x in some benchmarks
- 💪 Supports STM32, ESP32, nRF52

#### **[NNoM](https://github.com/majianjia/nnom)** ![](https://img.shields.io/github/stars/majianjia/nnom?style=social)
> **Higher-level neural network library for MCUs**
- 🎨 Keras-like API for embedded
- 📊 Built-in profiling and visualization
- ⚡ CMSIS-NN backend for speed
- 🏆 Perfect for prototyping

#### **[Qeexo AutoML](https://qeexo.com/automl/)**
> **Commercial solution - Used by Fortune 500**
- 🤖 Automated model creation & optimization
- 📱 Sensor fusion capabilities
- 🔋 Ultra-low power modes
- 💰 Free tier available for hobbyists

</td>
